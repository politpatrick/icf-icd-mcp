# GdB (Zeilenkennungen, vmg_spanne_pruefen, Prompts) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Einzel-GdB gegen eine Teil-B-Zeile prüfen und zwei geführte GdB-Abläufe anbieten.

**Architecture:** Zeilenkennungen und Spannenprüfung in `src/vmg.mjs` (Laufzeit, aus `data/versmedv.json`), Tool in `src/vmg_tools.mjs`, Warnung in `src/fall.mjs`, Prompts in `src/prompts.mjs`.

**Tech Stack:** Node ≥ 18, `node:test`, keine Abhängigkeiten.

**Spec:** `docs/superpowers/specs/2026-11-22-gdb-design.md`

## Global Constraints

- GdS-Wert nie ohne Pfad und Fundstelle; Hinweis auf Teil A Nr. 1.4; keine Wertung, kein Gesamt-GdB.
- Fehler als `LookupError` bzw. `PromptError` (-32602). Prompts nur bei `VMG_ENABLED`.
- Version 1.10.0.

## Review Focus

- Zeilenkennung in Kleinschreibung/ohne Leerzeichen („b3.7z2“) → erkannt.
- Z0, Z99, Zeilenkennung an Abschnitt ohne Zeilen → `LookupError` mit Hinweis.
- `gdb` als Text „40“ oder 35 → angenommen bzw. geprüft; 110, -10, „abc“ → Fehler.
- „wenigstens 80“ mit gdb 100 → innerhalb; „siehe oben“ → nicht_bestimmbar.
- `fall_vergleichen` mit Zeilenkennung → keine Regression.

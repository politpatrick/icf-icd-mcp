# Versorgungsmedizinische Grundsätze (VersMedV) – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein viertes Wissensnetz `vmg_*` für die Versorgungsmedizinischen Grundsätze. Es umfasst die GdS-Tabelle mit Gliederungspfaden, die Suche über Wortlaut und das K710-Stichwortverzeichnis, eine Prüfhilfe zum Gesamt-GdB ohne Rechenergebnis und die Merkzeichen.

**Architecture:** Zwei Python-Skripte erzeugen die Daten.

- `k710_extract.py` (pypdf, einmalig) zieht das Stichwortverzeichnis aus dem PDF als Text.
- `versmedv_to_json.py` (Standardbibliothek) baut daraus und aus dem amtlichen XML `data/versmedv.json`.

`src/vmg.mjs` stellt die Abfragen bereit. `src/vmg_tools.mjs` definiert die Tools und hängt sie wie das BI-Modul über einen Schalter in `src/protocol.mjs` ein. Die ICD-Ableitung nutzt eine neue Exportfunktion von `src/icd.mjs`.

**Tech Stack:** Node ≥ 18 ohne Abhängigkeiten (`node --test`), Python 3 (Standardbibliothek; pypdf nur für den einmaligen PDF-Auszug).

**Spec:** `docs/superpowers/specs/2026-11-17-versmedv-design.md`

## Global Constraints

- **Wortlaut:** Texte aus XML und K710 werden unverändert übernommen (§§ 62, 63 UrhG). Quellenangabe für K710: Herausgeber BMAS, Titel „Versorgungsmedizin-Verordnung – VersMedV – Versorgungsmedizinische Grundsätze“, Stand Januar 2026.
- **Kein Gesamt-GdB als Zahl:** Ausgaben enthalten keinen Schlüssel für einen Gesamt- oder „voraussichtlichen“ GdB.
- **GdS-Werte im Zusammenhang:** Ein GdS-Wert erscheint nur zusammen mit Gliederungspfad und Fundstelle (z. B. „Teil B Nr. 3.7“).
- **Kennzeichnung:** Stichwörter, ICD-Ableitungen und die B-18-Aufteilung sind als nicht amtlich gekennzeichnet.
- **Kennungen:** Präfix `VMG:`. Kanonische Form ist `VMG:<Teil> <Nummer>[<Buchstabe>][ <Doppelbuchstabe>]`, z. B. `VMG:B 3.7`, `VMG:A 5d jj`, `VMG:D 1e`.
- **Schalter:** `ICF_MCP_VMG=0` schaltet das Modul ab, standardmäßig ist es an.
- **Bestand bleibt:** ICF-, ICD- und BI-Tools ändern ihr Verhalten nicht. `fold()` bleibt unverändert.
- **Version** 1.6.0.
- **Branch:** `feat/versmedv`, abgezweigt von `feat/icd-alphabet`, solange PR #12 nicht gemergt ist (die ICD-Ableitung nutzt das Alphabet). Andernfalls von `origin/main`.

## Review Focus

1. Kennungen weggefallener oder aufgehobener Abschnitte (`B 1`, `D 3`) liefern einen Knoten mit diesem Status, keinen Fehler (Test in Task 3).
2. Eine Suche, die nur über das Stichwortverzeichnis trifft („Drogenabhängigkeit“ → B 3.8), findet den Abschnitt (Test in Task 3).
3. Ungültige Einzel-GdB in der Prüfhilfe (35, 110, −10, leere Liste) ergeben eine verständliche Fehlermeldung (Test in Task 4).
4. Ein ICD-Kode ohne passendes Stichwort liefert eine leere Ableitung, keinen Fehler. Ein unbekannter ICD-Kode liefert den Fehler der ICD (Test in Task 3).
5. `ICF_MCP_VMG=0` blendet alle `vmg_`-Tools und den Instructions-Absatz aus (Test in Task 3).

- **Ausgabe auf stdout:** Anzahl Knoten, GdS-Zeilen, Stichwörter, Rückfälle auf einen Vorfahren.

**Interfaces:**
- Produces:
  - `gesamtGdb({ einzel: [{ bezeichnung: string, gdb: number, funktionssystem?: string, kennung?: string }] }) -> { version, ausgangswert: number, ausgangseintrag: string, eintraege: [{ bezeichnung, gdb, funktionssystem: string|null, funktionssystem_quelle: "angabe"|"teil_b"|"verwaltungsueblich"|null, markierungen: [{ regel: "VMG:A 3.5", text }] }], paare: [{ a: string, b: string, beziehung: "gleich"|"moeglicherweise_gleich", grund }], regeln: [{ id, text }], hinweis }`
  - `merkzeichen({ merkzeichen? }) -> { version, merkzeichen: [{ zeichen, bezeichnung, fundstellen: [{ id, fundstelle, absaetze }] } | { zeichen, bezeichnung, norm, hinweis }] }`
- Feste Werte:
  - `hinweis` der Prüfhilfe lautet: „Es wird kein Gesamt-GdB berechnet. Nach Teil A Nr. 3 ist der Gesamt-GdB aus einer gutachterlichen Gesamtschau zu bilden; Einzel-GdB dürfen nicht addiert werden.“
  - `regeln` enthält A 3.1, 3.2, 3.3, 3.3.1–3.3.4, 3.4, 3.5 im Wortlaut aus den Daten.
  - Funktionssystem-Tabelle: B 2 bis B 17 → Kapiteltitel. B 18.9 und B 18.10 → „Rumpf“, B 18.13 → „Arme“, B 18.14 → „Beine“, übriges B 18 → „Haltungs- und Bewegungsorgane, nicht näher zugeordnet“. Die B-18-Werte tragen `funktionssystem_quelle: "verwaltungsueblich"`.
  - Merkzeichen: G → `VMG:D 1`, B → `VMG:D 2`, Gl → `VMG:D 4`, H → `VMG:A 4` und `VMG:A 5`, Bl → `VMG:A 6`. aG, RF und TBl bekommen eine `norm` außerhalb der VersMedV:
    - aG: § 229 Abs. 3 SGB IX
    - RF: Rundfunkbeitragsstaatsvertrag (§ 4)
    - TBl: Schwerbehindertenausweisverordnung (§ 3)

    Der Executor prüft die genauen Absätze an der Quelle (gesetze-im-internet.de, z. B. mit `curl -4`). Er zitiert nur, was er dort verifiziert hat, und hält das als Ruling fest.

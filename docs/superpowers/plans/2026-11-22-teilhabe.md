# Teilhabe (abgrenzung_egh_pflege, Prompts) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Orientierung Eingliederungshilfe/Pflege je ICF-d-Kategorie und zwei geführte Teilhabe-Abläufe.

**Architecture:** Logik in `src/teilhabe.mjs` (nutzt `bi.biForIcf`, `icf.getCode`, `LEBENSBEREICHE` aus `fall.mjs`), Tool in `src/teilhabe_tools.mjs` (nur bei `BI_ENABLED`), Prompts in `src/prompts.mjs`.

**Tech Stack:** Node ≥ 18, `node:test`, keine Abhängigkeiten.

**Spec:** `docs/superpowers/specs/2026-11-22-teilhabe-design.md`

## Global Constraints

- Orientierung, keine Zuständigkeitsentscheidung; kein Etikett „nur Pflege“; Herkunft kuratiert kennzeichnen.
- Fehler als `LookupError` bzw. `PromptError` (-32602). Version 1.11.0.

## Review Focus

- `D510.3`, ` d510 `, `d5` (Kapitel) → erkannt; Kapitel liefert Treffer über Unterkategorien.
- `b130`, `e310`, `x1`, `""`, Nicht-Text → Fehler je Kode, nicht Absturz.
- Doppelte Kodes → einmal ausgegeben.
- `ICF_MCP_BI=0` → Tool und Teilhabe-Prompts? (Prompts bleiben, nennen das Tool nicht).
- Kinder (`alter_monate` < 216) → § 35a SGB VIII im Prompt.

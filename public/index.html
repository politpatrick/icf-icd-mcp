ICF, ICD-10-GM, Begutachtungsinstrument & VersMedV MCP

MCP-Server zum Nachschlagen und Prüfen von ICF-Kategorien und ICD-10-GM-Diagnosen (deutsche Fassungen des BfArM) sowie von Kriterien und Ausprägungen des Begutachtungsinstruments nach § 15 SGB XI (Begutachtungs-Richtlinien 2026) und der Versorgungsmedizinischen Grundsätze (VersMedV, GdS/GdB, Merkzeichen).

Endpunkt

/mcp

Streamable HTTP, ohne Anmeldung, nur lesend. Die Seite selbst speichert nichts.

In Claude einbinden

  • claude.ai / Claude Desktop: Einstellungen → Konnektoren → Benutzerdefinierten Konnektor hinzufügen, obige URL eintragen.
  • Claude Code: claude mcp add --transport http icf-icd /mcp

Tools

Version wird abgerufen …

  • ICF: icf_search, icf_get_code, icf_list_chapters, icf_get_related, icf_compare, icf_get_qualifiers, icf_interpret_coding
  • ICD-10-GM 2026: icd_search, icd_get_code, icd_list_chapters, icd_check_code, icd_relations, icd_compare
  • Begutachtungsinstrument SGB XI: bi_search, bi_get_item, bi_list_structure, bi_related, bi_compare, bi_interpret_coding, bi_calculate, bi_icf_mapping, bi_scoring_rules, bi_gegenueberstellen
  • Prompts (geführte Abläufe): pflegegrad_interview, pflegegutachten_verstehen, gdb_antrag_vorbereiten, gdb_bescheid_verstehen, teilhabebedarf_erfassen, bedarfsfeststellung_verstehen, eigene_darstellung_vorbereiten
  • Versorgungsmedizinische Grundsätze (VersMedV): vmg_search, vmg_get, vmg_list_structure, vmg_gesamt_gdb, vmg_merkzeichen, vmg_spanne_pruefen
  • Fallprofil (Austauschformat für einen Fall): fall_schema, fall_pruefen, fall_vergleichen
  • Verfahrenswege allgemein erklärt: verfahren_info
  • Teilhabe oder Pflege (Orientierung je ICF-d-Kategorie): abgrenzung_egh_pflege
